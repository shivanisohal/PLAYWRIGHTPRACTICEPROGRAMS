# Playwright Practice Programs

This repository contains practice programs and examples for Playwright and JavaScript basics.

## Contents

- **javascriptBasic/** - JavaScript fundamental examples including hoisting and scope demonstrations

## Getting Started

1. Clone the repository
2. Navigate to the relevant folder
3. Run the JavaScript files with Node.js:

```bash
node javascriptBasic/hoisting.js
```
